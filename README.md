# Akshatha Portfolio Website

A responsive one-page portfolio built with HTML, CSS, and a small amount of JavaScript.

## Customize
1. Open `index.html`.
2. Replace `your.email@example.com` with your email.
3. Replace `https://www.linkedin.com/in/your-linkedin` with your LinkedIn URL.
4. Edit any project wording or metrics as needed.

## Preview locally
Double-click `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
